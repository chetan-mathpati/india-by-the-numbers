# India By the Numbers

Six lenses. One country.

India By the Numbers is an Excel dashboard built using public data to look at six areas of India:

1. Economy
2. Mobility
3. Agriculture
4. Environment
5. Population
6. Digital India

Each section brings together a few key numbers, charts and the story behind them.

## Dashboard

Open the Excel workbook:

`dashboard/India_By_the_Numbers.xlsx`

Start with the `00_HOME` sheet.

## Data

The raw datasets used in the dashboard are available in the `data` folder.

## Sources

`documentation/SOURCES.md`

## Notes

FY means financial year and CY means calendar year.

This is a personal portfolio project built for learning and demonstration. It is not an official statistical publication.
