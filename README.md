# India By the Numbers

Six lenses. One country.

India By the Numbers is an Excel data storytelling project built around six parts of the country: economy, mobility, agriculture, environment, population and digital payments.

The aim was simple: take public data that normally lives across different reports and websites and turn it into one clear, easy-to-explore view.

## What is inside

The workbook starts with a home page and then moves through six focused views.

1. Economy
2. Mobility
3. Agriculture
4. Environment
5. Population
6. Digital India

Each view combines headline figures, charts and a short explanation of what the numbers are saying.

## Data

The raw datasets used by the workbook are kept separately in the `data` folder.

The source tier is retained in the CSV files so it is clear which figures are marked as official, secondary or derived.

## Notes

FY means financial year and CY means calendar year.

This is a personal portfolio project for data storytelling and Excel work. It is not an official statistical publication. Figures should be checked against the original source before being used for formal reporting.
