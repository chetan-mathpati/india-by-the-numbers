# Data Dictionary

The CSV files in `data/` are the raw tables used by the Excel workbook.

| File | Main measure |
|---|---|
| economy.csv | Real GDP growth |
| economy_size.csv | Nominal GDP |
| mobility.csv | EV sales |
| mobility_states.csv | EV sales by state |
| agriculture.csv | Foodgrain production |
| agriculture_crops.csv | Crop output |
| environment.csv | PM2.5 |
| environment_aqi.csv | AQI category counts |
| population.csv | Population share by age group |
| population_median.csv | Median age |
| digital.csv | UPI transaction volume |
| digital_value.csv | UPI transaction value |

Each table also retains its source-tier field where it was present in the workbook.
